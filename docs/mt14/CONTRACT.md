# MT-1.4 隔离自动迭代合同 v1

本实现只写新建的 MT14 实验根。候选每轮最多两个（基本面、技术各一个）；候选不能改验证器、费用、窗口、样本门槛、风险退出或生产策略。基本面默认 ROE≥10、PE≤25、PB≤3；候选只收紧这些已有因子。技术默认沿用 signal-policy-v1，仅允许收紧突破量比。

主窗口为 60 个交易日，20/40 为诊断窗口，至少 20 个同股不重叠的独立前向事件；不能把同股重复信号、日历日或历史补抓算作样本。对照固定同范围、每代码 10000 资金槽、相同费用、同起止时点，未选择股票保留现金。净改善必须大于零、最大回撤和尾部收益不得恶化。收益是前向信号评价，不是可成交或个人盈亏证明；MT13 执行账本独立保留真实报价证据，日 K 不制造执行。

当前 sweep 只证明当前存续股票的快照，绝不还原历史 PIT。采集时点、发布日期、市场完成日、来源 hash、引擎版本和决策 hash 随轮次归档。真实首轮没有成熟样本时 continue_shadow，不降低门槛。工程失败为 incomplete，与策略决定分栏。

隔离实验晋级不等于生产 validated；原 methods.py、生产策略和 tracking-scope 不变。已有实验模拟仓及人工取消信号始终留在原版本账本，不迁移、不复活、不复制真实持仓。scheduled 永远为 false，next_check_at 只是建议检查时间。
